# OrderACharmMod_cloverpit
OrderACharmMod for Cloverpit based on https://www.nexusmods.com/cloverpit/mods/4 and coded for BepInEx

# Updated
✅ Any charm can be ordered, including special ones like the God's Eye.
✅ It does not consume any tickets.
✅ It does not check if you have enough tickets.
✅ You can queue up to 4 orders before the next restock.
✅ Upon reaching 4/4, the order button disappears or becomes inactive.
✅ After the restock, the 4 orders are processed, and the counter resets to 0/4.
✅ The setup from the previous restock remains in place.

# Instalation 
Copy OrderCharmMod.dll to C:\Program Files (x86)\Steam\steamapps\common\CloverPit\BepInEx\plugins
